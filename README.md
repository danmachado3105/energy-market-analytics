# ⚡ Energy Market Analytics

> Análise de dados do setor elétrico brasileiro utilizando Python, APIs e Business Intelligence.

## 📌 Sobre o projeto

O **Energy Market Analytics** é um projeto independente desenvolvido com o objetivo de explorar dados reais do setor elétrico brasileiro e demonstrar como ferramentas de **Python, APIs e Business Intelligence** podem ser utilizadas para transformar dados em informações relevantes para análise e tomada de decisão.

O projeto utiliza dados públicos disponibilizados por órgãos e instituições do setor elétrico, com foco em indicadores de consumo, demanda e evolução do mercado de energia.

## 🎯 Objetivos

- Trabalhar com dados reais do setor elétrico;
- Aprender e aplicar Python para análise e tratamento de dados;
- Consumir dados através de APIs;
- Desenvolver habilidades em Business Intelligence;
- Criar indicadores e visualizações utilizando Power BI;
- Identificar tendências e padrões nos dados;
- Transformar dados brutos em informações úteis para análise;
- Desenvolver uma visão mais próxima de um projeto de dados aplicado a um cenário empresarial.

## 📊 Análises

O projeto pretende explorar questões como:

- Como o consumo de energia evoluiu ao longo do tempo?
- Quais regiões apresentam maior participação no consumo?
- Quais períodos apresentam maior demanda?
- Existem padrões ou comportamentos sazonais?
- Quais indicadores podem ajudar na análise do mercado?
- Quais variações relevantes podem ser identificadas nos dados?

## 📈 Dashboard

O resultado das análises será apresentado em um dashboard desenvolvido no **Power BI**, permitindo visualizar indicadores, tendências e comparações de forma interativa.

> 🚧 Dashboard em desenvolvimento.

## 🐍 Análise com Python

Python será utilizado para:

- Coleta de dados;
- Consumo de APIs;
- Limpeza e tratamento;
- Transformação dos dados;

## 🔌 APIs

O projeto também explora o consumo de APIs relacionadas ao setor elétrico, permitindo trabalhar com dados de forma programática em vez de depender exclusivamente de arquivos estáticos.

## 💡 Insights

Uma das principais propostas do projeto é ir além da visualização dos dados.

Após o tratamento e análise, serão documentados os principais insights encontrados, explicando o que os dados indicam e por que essas informações podem ser relevantes para processos de análise e tomada de decisão.

Os dados utilizados serão provenientes de fontes públicas e oficiais relacionadas ao setor elétrico brasileiro, incluindo:

- Agência Nacional de Energia Elétrica — ANEEL

As fontes e conjuntos de dados utilizados serão documentados ao longo do projeto.
